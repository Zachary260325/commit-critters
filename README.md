# Commit Critters 🌱🏆

Co-authored by [Zachary260325](https://github.com/Zachary260325) and Codex to farm easy achievements, discover how achievements work on GitHub, and record the process.

[Achievement recipes](docs/ACHIEVEMENTS.md) · [Process](docs/PROCESS.md) · [Contributing](CONTRIBUTING.md)

## Try the critter

A tiny terminal creature reacts to your local Git activity. Requires Python 3.10+ and Git.

```sh
python3 critters.py --demo
python3 critters.py
python3 critters.py --quests
```

On Windows, use `py -3` in place of `python3`.
